# Projeto Banco de Dados
**Nome do projeto:** Confeitaria Sempre Doce
**Equipe de Desenvolvimento:** Natalia Gamero Scognamiglio

## **1. Visão Geral do Sistema (Escopo)**

A *Confeitaria Sempre Doce* deseja expandir sua atuação, criando um site para vender seus produtos que são feitos com muito amor e carinho, mantendo a tradição da sua família.

## **2. Requisitos Funcionais (RF)**

**RF01:** O sistema deve gerenciar o cadastro de seus clientes, as informações úteis que foram levantadas são:

 - Nome completo;
 - Telefone;
 - E-mail;
 - Endereço.

**RN02:** O sistema deve permitir que o cliente envie uma mensagem com as informações do seu pedido. A mensagem será enviada via formulário do sistema com as seguintes informações:

 - Nome Completo;
 - E-mail;
 - Telefone;
 - Endereço;
 - Texto da mensagem.
